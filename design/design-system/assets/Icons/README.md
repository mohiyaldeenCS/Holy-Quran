# Icons

نسخ SVG من مجموعة الأيقونات، بحبر واحد `#0E5A52` (لون `primary` على الورق). داخل التطبيق استخدم المكوّن `Icon`، فهو يأخذ لونه من `currentColor` ويتبع السمة.

خط ١٫٧٥ على شبكة ٢٤، وأطراف مدوّرة، بلا تعبئة إلا `play` و`pause`. السهمان `next` و`previous` مرسومان لاتجاه القراءة من اليمين إلى اليسار: «التالي» يشير إلى اليسار.
