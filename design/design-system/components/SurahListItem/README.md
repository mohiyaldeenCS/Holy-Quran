# SurahListItem

صف فهرس السور: الرقم داخل نجمة الربع، والاسم بخط ريم كوفي، ثم «مكية/مدنية · عدد الآيات»، وصفحة البداية.

- `ayat` رقم، ويُكتب معدوده صحيحًا تلقائيًا (`Quran.ayahCount`): ٧ آيات، ٢٨٦ آية، ٢٠٦ آيات.
- `lastRead` يضيف شارة «آخر قراءة» بنقطة ذهبية: النقطة العلوية في الرمز.
- البيانات من بيانات مصحف المدينة في التطبيق، لا تُكتب يدويًا.
