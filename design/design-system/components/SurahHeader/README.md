# SurahHeader

رأس السورة: إطار مزدوج (خارجي ١٫٥ بلون `ornament` وداخلي ١ بلون `ornament-soft`) ونجمتا الربع على الجانبين، والاسم بخط ريم كوفي ٦٠٠ بلون `primary`.

- `name` اسم السورة دون كلمة «سورة». `size`: `md` في الصفحة، `lg` في مقدمة السورة.
- `info` سطر اختياري تحت الإطار: مكية أو مدنية، وعدد الآيات، والترتيب. يفتح «مقدمة السورة».
- بعده سطر البسملة في الوسط، عدا سورة التوبة.
