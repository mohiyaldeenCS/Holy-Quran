# LevelSwitch

مفتاح مستوى الواجهة: بسيط · متوسط · دراسة. يغيّر الأدوات الظاهرة في التطبيق كله من إعداد واحد.

- بسيط: المصحف، والصوت، وآخر موضع، والعلامة، والتفسير عند الطلب. متوسط يضيف التجويد والحفظ والختمة والموضوعات. دراسة يضيف الإعراب والصرف والجذور والقراءات والمتشابهات وشجرة النحو.
- الرجوع إلى مستوى أبسط لا يحذف شيئًا من بيانات المستخدم.
- يعمل مضبوطًا (`value` و`onChange`) أو حرًّا (`defaultValue`).
- هو المفتاح المقطعي العام في التطبيق: يُستخدم بخيارات أخرى لمقدار السياق (آية · ٣ آيات · ٥ آيات · السورة) ولوضع الحفظ (ظاهر · الحالية مخفية · الكل مخفي)، ولا يُنشأ مكوّن جديد لكل مفتاح.
