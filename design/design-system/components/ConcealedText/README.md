# ConcealedText

نص الحفظ بعد حجب حبره. لا يُحذف شيء: النص باقٍ كلمةً كلمة تحت شريط `conceal` (خط سفلي `line-strong` وشريط بطول الكلمة)، فيبقى موضع كل كلمة وطولها ظاهرين ليتذكّر الحافظ.

- `children` الآية كما وردت من المصدر نصًّا واحدًا. علامة الوقف تبقى داخل شريط الكلمة التي قبلها.
- `revealed` يُظهر النص (لمسة مطوّلة، أو وضع «ظاهر»). وبقية الآيات في الصفحة تُعرض بـ`QuranText` عاديًا حتى يبقى السياق.
- لقارئ الشاشة يُقرأ «الآية مخفية» (`label`) ولا يُنطق النص، وإلا ضاع معنى الإخفاء. في وضع ألوان النظام (forced-colors) يصير الشريط بلون `GrayText`.
- الأوضاع: ظاهر · الحالية مخفية · الكل مخفي، تُختار بـ`LevelSwitch` بخيارات «ظاهر»، «الحالية مخفية»، «الكل مخفي».
