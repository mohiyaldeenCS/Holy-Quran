# WordSheet

الورقة المنزلقة لدراسة كلمة: تبويبات (النص، التفسير، الإعراب، الصرف، التجويد)، ثم الكلمة بحجم `quran-focus`، ثم صفوف «تسمية · قيمة».

- يقدّم المستهلك `word` كما في النص، و`position`، و`rows` أزواجًا، و`note` لذكر المصدر. لا تُعرض معلومة لغوية بلا مصدر.
- في هذه المعاينة عدد ورود الجذر محسوب من مدوّنة القرآن العربية (Quranic Arabic Corpus).
