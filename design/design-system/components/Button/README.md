# Button

الأزرار: ارتفاع ٥٢، زوايا ١٦، نص ١٧ نصف عريض. الارتفاع الأدنى ٤٨ والنص لا ينقص عن ١٧.

- `variant`: `primary` (زمرد، مرة واحدة في الشاشة لما وُجدت الشاشة له)، `outline`، `tonal` (ذهب فاتح للإضافة إلى مجموعة)، `text` (إلغاء وإجراءات ثانوية).
- `icon` اسم أيقونة اختياري قبل النص. الفعل أولًا: «ابدأ التلاوة»، «تابع القراءة».
- في السمة الليلية يصير الأساسي ذهبيًا ونصه زمرد أعمق، كما في شاشة الدراسة.
