# TajweedKey

مفتاح أحكام التجويد الثمانية. لكل حكم لون (`tj-*`) وعلامة خطية واسم، فلا يُترك التمييز لحاسة اللون وحدها.

- أحكام النون والميم بخط تحت الحرف: غنّة منقّط، إدغام متصل، إخفاء متقطّع، إقلاب مزدوج، قلقلة متموّج. والمدود بخط فوق الحرف: طبيعي رفيع، متصل ومنفصل سميك، لازم خطّان.
- `compact` يعرضه حبّةً صغيرة تحت النص. وداخل النص يلفّ `Quran.Tajweed` الحروف التي يقع عليها الحكم فقط.
- ألوان السمة الليلية والتباين العالي درجات أفتح من الألوان نفسها.
