# RepeatDots

نقاط عدّاد التكرار: المنجز مملوء بالزمرد، والجاري حلقة ذهبية ٣ بكسل بداخلها ذهب فاتح، والقادم حلقة فارغة بحدّ `line-strong`. الأشكال الثلاثة تختلف بالتعبئة والسُّمك لا باللون وحده.

- `total` و`done`: عدد المنجز؛ الجاري هو ما يليه. `label` اختياري، والافتراضي «التكرارات المنجزة: ٣ من ٧» لقارئ الشاشة.
