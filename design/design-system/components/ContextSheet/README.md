# ContextSheet

ورقة منزلقة تُظهر الآية بين ما قبلها وما بعدها، تُفتح من زر «سياق الآية» في نتيجة البحث.

- مفتاح المقدار (آية · ٣ آيات · ٥ آيات · السورة) هو `LevelSwitch` نفسه بخيارات أخرى. `options` و`value` و`defaultValue` و`onChange`.
- `children` النص القرآني حرفًا بحرف من المصدر، مع فاصلة كل آية؛ الآية المطلوبة تُلفّ بصنف `qk-hl-select` (خلفية وإطار) وتُلفّ الكلمات المطابقة بـ`Match`.
- في الأسفل «افتح في المصحف» (الزر الأساسي الوحيد) وزر تشغيل من هذه الآية. `reference` يُكتب بخط ريم كوفي في الرأس.
