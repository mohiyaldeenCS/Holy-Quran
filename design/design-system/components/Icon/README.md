# Icon

مجموعة أيقونات خطية على شبكة ٢٤: خط ١٫٧٥ بأطراف مدوّرة، بلا تعبئة إلا التشغيل والإيقاف. تأخذ لونها من `currentColor`.

- الأسماء: `home` `mushaf` `listen` `study` `search` `bookmark` `play` `pause` `download` `night` `settings` `repeat` `index` `khatma` `next` `previous` `more` `alert` `check` `close` `mic` `eye` `sort` `minus` `plus` `context` (القائمة في `Quran.iconNames`).
- الأسهم تتبع اتجاه القراءة: `next` يشير إلى اليسار و`previous` إلى اليمين. أيقونة التشغيل لا تنعكس.
- مرّر `label` حين تكون الأيقونة وحدها تحمل المعنى؛ وإلا فهي زخرفية مخفية عن قارئ الشاشة.
- الستة الأخيرة للبحث والحفظ: `mic` (البحث بالصوت)، `eye` (إظهار الآية المخفية)، `sort`، `minus` و`plus` (المُعدّل)، `context` (سياق الآية).
- نسخ SVG منفصلة في مجموعة Icons بلون `#0E5A52` للأدوات التي لا تقرأ هذه الحزمة.
