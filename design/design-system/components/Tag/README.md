# Tag

وسم تصنيف للعلامات والملاحظات والمجموعات. لكل تصنيف شكل ولون واسم، فلا يُترك التمييز للون وحده.

- `shape`: `circle` حفظ، `square` مراجعة، `diamond` دراسة، `ring` آيات مهمة؛ التصنيفات المخصصة تختار من الأشكال الأربعة.
- `color` قيمة CSS (يُفضّل متغير من الرموز). `selected` يجعله زمردًا فاتحًا.
