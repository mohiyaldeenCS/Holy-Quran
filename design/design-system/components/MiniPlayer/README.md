# MiniPlayer

بطاقة المشغّل الزمردية: السورة والآية بخط ريم كوفي، واسم القارئ، والسرعة، وشريط تقدّم ذهبي، وخمسة أزرار: تكرار، والآية السابقة، وتشغيل/إيقاف (ذهب ٦٠ بكسل)، والآية التالية، ومؤقت النوم.

- `repeat` عدد مرات التكرار يظهر شارةً على زر التكرار. `playing` يبدّل أيقونة الزر الكبير.
- اسم القارئ يأتي من بيانات التطبيق؛ لا يُكتب اسم قارئ حقيقي في التصاميم.
