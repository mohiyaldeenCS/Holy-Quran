# Stepper

رقم يُعدَّل بزرّي إنقاص وزيادة، كلٌّ منهما بحجم لمس ٤٨. للإعدادات الصغيرة: عدد التكرار، وتكرار الدمج، ومدة الصمت.

- `label` و`value`/`defaultValue` و`min` و`max` و`unit` و`onChange(n)`. الرقم يُكتب بالأرقام العربية، وتُعطَّل الأزرار عند الحدّين.
- اسم كل زر لقارئ الشاشة يحمل اسم الإعداد: «زيادة تكرار كل آية». القيمة منطقة حيّة تُعلن عند تغيّرها.
