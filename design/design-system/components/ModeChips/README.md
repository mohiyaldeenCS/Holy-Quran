# ModeChips

حبّات أنواع البحث: كلمة، الجذر، بلا تشكيل، المشتقات، في التفاسير، الموضوعات. واحد منها مختار دائمًا.

- المختار يأخذ خلفية `primary-soft` وخطًا أعرض **وعلامة صح** قبل نصه، فلا يُترك التمييز للون.
- الصف يُمرَّر أفقيًا إذا ضاق؛ ارتفاع كل حبّة مرئيًا ٤٠، ومنطقة اللمس ٤٨. `options` و`value` و`defaultValue` و`onChange(index)` و`label`.
- الجذر وما يشتق منه محسوبان من مدوّنة القرآن العربية، فيُذكر المصدر في نتائجهما.
