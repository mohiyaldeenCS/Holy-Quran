# AyahMarker

فاصلة الآية: دائرة ذهبية رقيقة (`ornament`) ورقم الآية بداخلها بخط الواجهة ٦٠٠ بلون `accent`.

- `number` رقم الآية (يُكتب بالأرقام العربية المشرقية تلقائيًا)، `size` ٢٦ في صفحة المصحف و٣٦ في صف الآية.
- `playing` يملأ الدائرة أثناء تلاوة الآية، مع خلفية `highlight-ayah` على نصها.
- الفاصلة هي نفسها هدف اللمس لفتح أدوات الآية؛ لا تُستبدل بأقواس.
