# SearchResult

بطاقة نتيجة واحدة: الموضع («البقرة · الآية ٤٥»)، وزرّان (سياق الآية، افتح في المصحف)، ثم الآية كاملة بخط المصحف ٢٢.

- الكلمة المطابقة تُلفّ بـ`Match`: خلفية `search-match` **وخط سفلي بلون `info`**، فهي ظاهرة لمن لا يميّز الألوان. يلفّ المستهلك الكلمات المطابقة بحسب الجذر أو الكلمة، ولا يغيّر حرفًا من النص.
- `clamp` لآية طويلة: تُقطع عند نحو ثلاثة أسطر بتلاشٍ وتحتها «الآية طويلة · اعرضها كاملة» ليقرأها المستخدم كاملة. لا يُلخَّص نص قرآني.
- زرّا الإجراء ٤٨ بكسل. `onContext` و`onOpen`.
