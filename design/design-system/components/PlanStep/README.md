# PlanStep

صف من تسلسل الجلسة في خطة الحفظ: الآية ثم تكرارها، وبعد كل آية جديدة «دمج» بما سبقها: ١ ثم ٢ ثم ١–٢ معًا ثم ٣ ثم ١–٣ معًا، وهكذا.

- `state`: `done` (دائرة زمردية بعلامة صح)، `current` (حلقة ذهبية، وخط عريض، وبطاقة)، `next` (حلقة فارغة). الأشكال تختلف ولا يُكتفى بلون.
- `merge` يضيف كلمة «دمج» بلون `accent`. `title` و`repeats` نصان يحسبهما المستهلك.
- الصف الحالي يحمل `aria-current="step"`، وللمنجز نص مخفي بصريًا «تمّت».
