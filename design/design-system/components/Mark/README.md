# Mark

رمز التطبيق: نجمة الربع (مربعان متراكبان) تحتضن كتابًا مفتوحًا، وفوقه النقطة العلوية التي تعني «موضع القراءة الحالي».

- `size` بالبكسل. تحت ٣٢ تُحذف النقطة تلقائيًا، ويزداد سُمك خط النجمة كلما صغر الحجم (٢٫٢ عند ٩٦ فأكثر، و٦٫٥ عند ٢٤).
- `variant`: `paper` على أرضية السمة (الافتراضي؛ يأخذ `ornament` و`brand-ink` فيتبع السمة)، `emerald` على الزمرد، `dark` على الزمرد الأعمق، `mono` بلون `currentColor` للطباعة والتطريز.
- `decorative` عندما يجاور الاسمَ نصٌّ يقول «القرآن الكريم»، حتى لا يُقرأ مرتين.
- لا يُمطّ ولا يُدوَّر ولا يُمال، ولا تُضاف إليه ظلال، ولا يوضع على خلفية قريبة من لونه. أصغر حجم ٢٤ بكسل.
