# Lockup

الرمز مع الاسم «القرآن الكريم» بخط ريم كوفي ٧٠٠. الرمز على يمين الاسم لأن القراءة تبدأ منه.

- الأفقي على الورق هو الصيغة الافتراضية؛ `onEmerald` لشاشة البداية وبطاقات المشاركة؛ `stacked` للأغلفة وشاشات التحميل.
- المساحة الآمنة حوله نصف عرض النجمة من كل جانب. أقل عرض للشعار الأفقي ١٢٠ بكسل، وما دون ذلك يُستخدم الرمز وحده.
- الاسم هنا مضبوط بخط ريم كوفي مؤقتًا؛ الكلمة الشعارية النهائية تُرسم يدويًا قبل الإطلاق، وعندها تُستبدل ملفات `assets/Logos/lockup-*`.
