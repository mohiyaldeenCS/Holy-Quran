# QuranText

حاوية النص القرآني بخط أميري قرآن. `size`: `page` (٢٥/٢٫٣ لصفحة المصحف)، `ayah` (٣٤/٢٫٣)، `focus` (٤٤/٢)، `compact` (٢٢/٢٫٢ لنتائج البحث وورقة السياق والحفظ).

- مرّر النص كما ورد من المصدر المعتمد حرفًا بحرف؛ لا يُركَّب من أجزاء ولا يُعدَّل. هذه المعاينة تستخدم نص مشروع تنزيل العثماني ١٫١ المصمَّم له خط أميري قرآن. النص وخطه زوج واحد: نص مجمع الملك فهد يحتاج خطه الخاص.
- أصناف التمييز داخل النص: `qk-hl-ayah` للآية المسموعة، `qk-hl-word` للكلمة المنطوقة (خلفية وخط سفلي)، `qk-hl-select` للآية المختارة، `qk-hl-search` لنتيجة البحث.
- لا تباعد بين الحروف، ولا عريض أو مائل، ولا يوضع فوق صورة.
