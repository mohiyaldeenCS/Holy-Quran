## Key interfaces

```dart
// spike/s7/gesture_target.dart (design carried to M1.2 and M1.6)
sealed class GestureTarget {}
final class WordTarget extends GestureTarget { final QuranAddress word; }
final class WaqfMarkTarget extends GestureTarget { final QuranAddress ayah; final int mark; }
final class MarkerTarget extends GestureTarget { final QuranAddress ayah; }
final class MarginTarget extends GestureTarget {}

// spike/s7/target_geometry.dart
final class TargetGeometry {
  factory TargetGeometry.of(SurahParagraph paragraph);
  List<Rect> get lineBands;
  Map<QuranAddress, List<Rect>> get words;
  Map<(QuranAddress, int), Rect> get marks; // gap plus mark cluster
  Map<QuranAddress, Rect> get markers;
}

// spike/s7/tap_resolver.dart (pure)
enum TapRule { exact, nearestOnLine, priorityZones, priorityZonesWithSlop }
GestureTarget resolveTap(Offset p, TargetGeometry g, TapRule rule, {double minTarget = 48});

// spike/s7/text_size_ladder.dart: 0.8, 0.9, 1.0, 1.15, 1.3, 1.5, 1.75, 2.0 (provisional, RD-07)
double stepAfterPinch(double current, double scale);

// spike/s4
enum WidgetLook { paper, night }
AyahWidgetFace({PackText ayah, PackText surahName, int ayahNumber, double quranSize, WidgetLook look, Size size});
double? fitQuranSize(PackText ayah, Size inner, {double from = 28, double to = 22});
typedef WidgetSlotInfo = ({String address, int slotStartMs, String lightPath, String darkPath,
    String packTextSha256, int lightBytes, int darkBytes, int renderMs});
```

`SurahParagraph` and `SurahBlockContent` gain `marks` and `markBoxesOf(ayah, mark)`;
`SpikeSurahText` gains `marks`. The block's own tap recogniser gives way to one
gesture layer per block, resolving targets from geometry; markers are display only.

## Tests and where they are measured

- Linux, every push (`flutter test spike`): the D-083 writer and checks on synthetic
  packs; tap-resolver and gesture-conflict tests (tap and double-tap: no double-tap
  recogniser, since one delays every tap by 300 ms against `NF-05`; tap and long press
  at 500 ms; tap and scroll beyond 18 px; a tap that stops a fling opens nothing;
  pinch against scroll); the size ladder keeps the focal ayah; synthetic pages (RTL,
  zoom clamp, pan before turn, reduce-motion fade); the S4 face draws the pack's
  bytes, colours from tokens, fit gives 28, less or null, offscreen render without app
  ancestors; the gesture log and widget metadata hold numbers and addresses only.
- CI on the real text (`spike-s1-text`): the S1 counts on the D-079 file (expected
  from part 1: 81,812 tokens, 77,433 words, 4,379 marks, 70 code points, no U+06DE;
  a difference is a finding, recorded and never adjusted) and the whole integrity
  suite including the D-083 checks for the first time on real text; S7 target
  geometry and rule accuracy over all 6,236 ayat; S4 fit counts at 4x2 and 2x2.
- Device (the profile APK): S7 target practice and the usability script; NF-05
  latency; pinch-release and page-turn frames; S4 pin, pixel check, shaping
  comparison, dark switch, rotation by date, resize, tap to open (WG-02), TalkBack.
  The session runs S1 first, then S7, S4, S3, and S5 last.
