text with inline markers, M1.2, M1.3, M1.8, after the S1 findings); the copy sheet
(SH-01 format, M1.6); the SH-03 fitting logic (M1.6); `ResourceRow` states beyond the
reference's three (M1.4); Tag category colours (O-14, M1.6); Phase 2 components;
screen layouts (their milestones).

Every component keeps Quran text to one ayah or one word with no inline marker, so
the S1 placeholder reordering does not arise here.
