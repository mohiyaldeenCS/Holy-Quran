M0.2 section of `docs/IMPLEMENTATION_PLAN.md`. Owner decisions that apply: D-050 and

follow-system mechanism; fonts in `assets/fonts/` with the hash test and the three
OFL texts; the three type questions; icons generated from `ICONS`; the widgets

`ayahCount`; the debug gallery; goldens, contrast test, guards.

Left out on purpose:

- `timesCount` (arrives with `MiniPlayer` and memorisation).
- Highlights inside `QuranText`, inline `AyahMarker`s in flowing text and
  `text-align-last: center` for the page size: spike S1 and M1.2. In M0.2 the page
  size is justified only (partial, stated in the pull request).
- Tapping `AyahMarker` (no consumer before M1.6); its semantics label is built now.
- `PackText` as the `QuranText` input: M0.3 (D-036). M0.2 takes a `String`.
- Persisting the theme choice and the settings screen: M1.1.
- The seven new icons of D-051: drawn and shown to the owner before M1.6, not in M0.2.

## Key interfaces

- `tokens.g.dart`: `AppColors extends ThemeExtension` (one field per semantic token,
  four `static const` instances, `byId`, `copyWith`, `lerp`); `AppShadows` (empty for
  `contrast`); `AppTextStyles` (15 `static const TextStyle`s, `letterSpacing: 0`,
  `TextLeadingDistribution.even`, no fallback on Quran styles); `AppFonts`,
  `AppSpacing`, `AppRadius`, `AppSizes`. Names are token names in camelCase.
- `ramps.g.dart`: `Ramps`, the 17 literal palette values; imported only under
  `lib/ui/core/`.
- `icon_paths.g.dart`: `enum IconName` in `ICONS` order; `Path buildIconPath(IconName)`;
  `bool isIconFilled(IconName)`; `Path buildMarkBookPath()`.
- Colours: `#RRGGBB` → `Color(0xFFRRGGBB)`; `rgba` → `Color.from(alpha: …)`, exact.
  CSS shadows → `BoxShadow` with the CSS blur converted to Flutter's sigma.
- `enum ReadingTheme { paper, night, sepia, contrast }`; `ThemePreference({theme,
  followSystemDark})`.
- `ThemeData buildAppTheme(ReadingTheme)`; `QuranApp({router, themePreference})`:
  with follow on and the chosen theme `paper` or `sepia`, `darkTheme` is `night` and
  `themeMode` is system; with `contrast` it stays `contrast` (D-053).
- Widgets keep the identity's names; files import Material with
  `hide Icon, IconButton, Switch, TabBar`. Reference heights become minimum heights so
  text can scale to 200%; `AyahMarker` scales its diameter; `Lockup` is a logotype
  and does not scale with text.

## Tests

- Generator unit tests and a guard that runs `generate.dart --check` and finds no
  Arabic character in any `.g.dart` (so `sample` and `usage` never reached it).
- Theme: instances and follow-system cases with `platformBrightnessTestValue`.
- Fonts: SHA-256 equal to `design/README.md`; OFL files identical; manifest families.
- Reem Kufi probe: `w700` renders identical to `w400` + `FontVariation('wght', 700)`
  and different from `w400`. If not identical, the generator adds `fontVariations`.
- Per widget: semantics, tap-target guidelines, no overflow at 200% on 360 wide,
  focus ring only in keyboard mode, reduced motion, a golden in each theme.
- Contrast: the pairs, thresholds and exceptions of `docs/DESIGN_SYSTEM.md`, plus
  newly found values (sepia `tj-ghunna` 4.24 and `tj-madd-wajib` 4.39 on `surface`;
  the `Switch` off track `line` 1.3–1.5:1 on `ground` and `surface`), each asserted at
  its value so any change fails.
- Goldens: tag `golden`; created by CI started by hand with the `goldens` task on
  `ubuntu-24.04`, which commits them to the branch; compared by normal CI. Sessions
  run `flutter test --exclude-tags golden test tools/gen/test` and never commit
  locally made images.
